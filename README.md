# Roni Leibovitch

A brutalist, non-linear portfolio for author, artist, photographer, and creative technologist Roni Leibovitch.

Inspired by [Real Life Magazine](https://reallifemag.com/) — spatial navigation, kinetic typography, and asynchronous storytelling across the viewport.

## Features

- **Non-linear spatial canvas** — drag, pan, and wander; content lives in zones, not rows
- **Sensory-friendly controls** — calm motion, soft palette, and focus mode
- **Kinetic typography** — animated title, floating words, async story fragments
- **Neurodivergent-friendly navigation** — constellation nav, minimap, keyboard arrows, no forced scroll path
